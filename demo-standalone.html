🚀 Demo: checkDraftWithDialog

Lưu ý: File này là demo standalone. Để test đầy đủ với IndexedDB và Fluent UI Dialog, bạn cần build library và chạy trong môi trường có React và @fluentui/react.

Hướng dẫn test:

  1. Nhập thông tin vào form (name, email, phone, file)
  2. Click "Save Draft" để lưu vào localStorage (demo đơn giản)
  3. Click "Test Restore" để test dialog restore
  4. Hoặc refresh trang (F5) - trong app thật sẽ tự động hiển thị dialog
Lưu ý: File này chỉ demo UI. Để test đầy đủ với IndexedDB, hãy import component DraftCheckDemo vào project React/SPFx của bạn.
